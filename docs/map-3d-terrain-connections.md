# Connected 3D terrain plan

Proposed follow-up to the [3D map playbook](map-3d-style.md). This is a visual terrain plan;
the current implementation still renders independent tile terrain. Gameplay, ownership and
construction remain tile-based.

1. **Define shared edges.** In `SceneBuilder`, index known tiles by axial coordinates before viewport culling. Use `HEX_NEIGHBORS` for six-bit masks and pair edge `i` with `(i+3)%6`. Give each pair one ordered cross-section, reversed for its neighbor. Close edges at the discovery frontier until the neighbor is known. Keep the existing projection, tile IDs, terrain categories, costs and conductor routing.
2. **Join the water first.** Triangulate each lake from its level water core to a shared, wide wet interval on each lake–lake edge. Reconcile corners using the three incident cells. Keep interior corners wet and bend the banks around exposed corners into one outer shoreline. Emit one bank strip per shoreline segment, with matching joins and no raised strip on an interior lake edge. Keep ocean water edge-to-edge, match its level and edge material at lake mouths, and taper lake banks into the coast. Preserve existing river ports and their cross-section.
3. **Build mountain saddles.** Connect off-center peaks to a low shared saddle on each mountain–mountain edge. Grade unconnected edges to the ground. Reserve the existing clearance bucket and suppress a saddle on both sides if either pad intersects its collar. Use a coordinate hash to select a few interior peak, shoreline and tint variants. Keep shared samples and water-edge color fixed across variants.
4. **Retain tile-sized meshes.** Feed each tile’s triangles to the existing depth picker and keep its fog and ownership overlay. Preserve HTML targets and the SVG fallback. Key reusable meshes by normalized edge/corner states, clearance and variant. Bound unused CPU entries and retain the existing GPU eviction and culling based on model extent. Invalidate the affected cell and its neighbors on discovery or clearance changes. Camera, fog-only and simulation updates reuse mesh geometry.
5. **Verify in stages.** Land edge descriptors and water before mountain relief. Test matching world-space samples, closed shores, concave corners and no pad overlap. Delete one reciprocal edge in a test fixture to prove the seam assertion catches it. Extend scene and browser tests for relief hits, fog, panning and context restoration. Compare both themes and production draw calls, triangles, retained meshes and frame timing at 1280, 390 and 360 px against the existing budgets.

**Risks.** Overbright banks and tall foreground peaks can obscure buildings, labels and ownership. Mask combinations can fragment instancing. Keep profiles simple and reduce variants if representative production captures show either problem.
