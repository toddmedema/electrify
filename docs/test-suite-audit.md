### Decisions and coverage mapping

- Delete `app-spacing.spec.ts`: exact 8/16 px gutters and adjacent-card gaps assert cosmetic implementation. Its useful storage metrics/review/overflow checks already run in `build-options.spec.ts` and `multiline-text.spec.ts`; manual scrolling is covered in `manual-sticky-headers.spec.ts`, event interaction in `event-interface.spec.ts`.
- Delete `pane-header-spacing.spec.ts`: exact header/status/progress-bar seam measurements are low-signal pixel coupling. Retain interactive/sticky/resizing checks in `pane-sticky-headers.spec.ts`, `pane-sizing.spec.ts`, `mission-evidence.spec.ts`; year-progress behavior/accessibility remains in `tutorial-auto-advance.spec.ts`, touch Build targets in `unified-design.spec.ts`.
- Merge `investor-objectives.spec.ts` into the existing Carbon Fee case in `victory-conditions.spec.ts`: preserve both the pregame percentage promise and the live absolute customer requirement, including pregame dialog fit, without restarting the same scenario in another suite.
- Delete `responsive-320.spec.ts`: setup/search/overflow are already exercised at 320 px in `custom-location-picker.spec.ts`; carry the hidden-keyboard-shortcuts check into `settings-responsive.spec.ts`, whose phone usability journey now covers both 320 and 390 px. Drop the incidental avatar/action overlap measurement. Merge the low-height footer case with the existing saved-game case in `main-menu.spec.ts`.
- Replace `main-menu-spacing.spec.ts` with `main-menu.spec.ts`: keep install/sound prompt independence in both themes; combine short-screen reachability with/without a save in one journey and check actual button/link reachability and non-overlap. Drop repeated exact 8 px gap/260 px width assertions and absence of obsolete promotional copy.
- In `home-motion.spec.ts`, remove exact decorative sweep timestamps, frequency, and hard-coded SVG path-coordinate alignment checks. Preserve reduced-motion enforcement, decorative aria-hidden semantics, and usable primary action. The removed animation choreography is deliberately no longer contractual.
- In `facility-row-surfaces.spec.ts`, drop the hover/transparent-child/border/shadow implementation test. Retain the storage tutorial ring/expanded-details regression; facility disclosure/drag behavior remains in `facility-drag-targets.spec.ts` and `unified-design.spec.ts`.
- Validation exposed a retained Storage tutorial setup race: clicking Build before tutorial initialization completed opened a transient catalog that was replaced by the entering game card. Wait for the real `Tap Build` objective and one settled main card before interacting; keep the ring/details assertions unchanged.
- Validation also exposed sticky-header fixture assumptions: the default chart stack can fit without scrolling, and a computed `overflow-y: auto` ancestor may have zero scroll range. Give the chart stack explicit scrollable fixture height (as the Events sibling already does), select the nearest ancestor with actual overflow, and require scrolling to advance before measuring pinning. This prevents vacuous desktop passes and exercises the short-phone outer scroller.
- In `intertie-order.spec.ts`, drop duplicate row separator/transparency and exact chevron-inset assertions; retain real keyboard and pointer/touch reordering, focus, cancellation/clock restoration, independent generator order, overflow, and minimum drag target height.
- In `ui-controls-regression.spec.ts`, drop its separate intertie dialog-geometry journey: `multiline-text.spec.ts` already opens that same intertie review in both themes across the viewport matrix and checks title/close separation, text bounds, overflow and reachable dialog actions. Keep the synthetic two-location wide-map clustering regression and target sizes.

No deleted/renamed spec was explicitly selected by CI or referenced in `.github/`, `scripts/`, `docs/`, README.md, or AGENTS.md. The CI-selected smoke/layout filenames are unchanged.

## Performance follow-up: October 21, 2026

The timing inventory and focused runs pointed to repeated forecast work in Insights. Layer,
preset and viewport controls now reuse a frozen real game and its frozen real projection,
with simulation data reset before each case. Cache-invalidation regressions keep independent
games. The overlapping unsaved/saved preset journeys share their editing setup while retaining
both remounts and restore behavior, and now verify the displayed layer order. An icon-component
assertion was replaced with the enabled, named control it represented.

Projection tests inspect the real generator's arguments and a detached copy of its enumerable
output, avoiding four duplicate twenty-year simulations. Copying before returning preserves
detection of downstream mutations; omitting hidden metadata matches the original equality.

Paired local runs on Node 24.14.0 used `test:ci -- --runInBand --runTestsByPath` with the two
files below and coverage enabled. These are single-run timings, not runtime ceilings or an
estimate of whole-suite savings.

| Suite | Before | After |
| --- | ---: | ---: |
| `src/components/views/Insights.test.tsx` | 27.456 s | 23.058 s |
| `src/helpers/Projection.test.ts` | 6.113 s | 5.833 s |
| Combined suite time | 33.569 s | 28.891 s (14% lower) |

All 42 retained cases passed, compared with 43 before consolidation. The focused coverage
runs do not meet repository-wide coverage thresholds on their own. Valid forecast cases passed;
temporary wrong-input and in-place-output mutations both failed at the intended assertions.

identified output aliasing and mutable simulation-data leakage; both were corrected before
integrated validation.

All fourteen `npm run check:ci` gates passed, including repository-wide coverage thresholds,
long simulations, tick performance, production builds, browser layouts and multiplayer.

Weather validation was already below one second locally. The data-center calibration matrix,
simulation seed/difficulty matrices, golden outputs and import/replay safety checks remain:
their distinct domain coverage does not justify further trimming in this pass.
