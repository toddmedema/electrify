- `InterVariable-Italic.woff2`: `e564f652916db6c139570fefb9524a77c4d48f30c92928de9db19b6b5c7a262a`

The upright face is preloaded; italic loads only when used. MUI, plain HTML and chart canvases share this family. No external font service is needed at runtime. When updating the font, verify dense gameplay values and construction cards at desktop, 390 px and 320 px widths, including both themes.
